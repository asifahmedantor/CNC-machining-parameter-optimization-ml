# 📌 Overview

This project presents a machine learning-based system for predicting CNC machining surface roughness (Ra) and exploring machining parameter combinations for improved surface quality.

The system uses **depth of cut, feed rate, cutting speed, material type, and cutting tool** as input parameters. Multiple regression algorithms are evaluated to identify the model with the strongest predictive performance.

The project combines machine learning prediction with a model-based parameter search to identify machining conditions associated with lower predicted surface roughness.

An interactive Streamlit application provides surface roughness prediction, model comparison, feature analysis, parameter-effect analysis, 3D visualization, parameter search, and downloadable reports.

> **Important:** Parameter recommendations generated by this project are model predictions and have not been experimentally validated on a physical CNC machine.

---

# 📚 Dataset Description

The consolidated machining dataset contains **453 observations** and **8 recorded variables**.

Among these observations, there are **295 unique machining parameter combinations**.

The dataset contains equal representation from three workpiece materials:

- **20MnCr5:** 151 observations
- **EN AW-6082:** 151 observations
- **41Cr4:** 151 observations

The recorded machining process is described in the available metadata as **longitudinal turning on an NTX 1000**, and the recorded cutting tool is **DNMG150608**.

## Dataset Variables

| Variable | Role | Range / Values |
|---|---|---|
| Depth of Cut (ap) | Input | 0.25–1.50 mm |
| Feed Rate (f) | Input | 0.10–0.30 mm/rev |
| Cutting Speed (Vc) | Input | 100–300 m/min |
| Material | Input | 20MnCr5, EN AW-6082, 41Cr4 |
| Cutting Tool | Input | DNMG150608 |
| Surface Roughness (Ra) | Target | 0.288–3.944 µm |

The dataset also contains:

- `Sample_ID`
- `Experiment_Path`

These fields are retained for sample identification and traceability and are not used as predictive machining features.

The consolidated dataset used by the project is stored at:

```text
data/processed/master_machining_dataset.csv
```

Additional machining metadata is stored in:

```text
data/processed/metadata_inventory.csv
```

The metadata includes information such as Ra, Rz, depth of cut, feed rate, cutting speed, material, tool, measurement identifiers, and numerical-control signal references.

> Model predictions should be interpreted within the scope and parameter ranges represented by the available dataset.

# 📊 Model Evaluation

Model performance is evaluated using:

- **R² Score**
- **Mean Absolute Error (MAE)**
- **Root Mean Squared Error (RMSE)**

An initial random row-wise train/test split was used during early development.

However, analysis of the dataset identified repeated machining parameter combinations. Of the 453 observations, there are 295 unique input combinations.

Because random row-wise splitting can place repeated machining conditions in both training and test data, a stricter **group-aware validation strategy** was subsequently implemented.

---

# 🧪 Group-Aware Validation

A machining-condition group is defined by the combination of:

```text
Depth of Cut
+
Feed Rate
+
Cutting Speed
+
Material
+
Tool
```

Rows containing identical machining parameter combinations are assigned to the same group.

This ensures that an identical machining condition cannot be divided between the training and validation portions of a fold.

## Group Holdout Verification

A separate group-aware holdout test was first performed.

```text
Total observations          : 453
Unique machining conditions : 295
Training observations       : 365
Testing observations        : 88
Training conditions         : 236
Testing conditions          : 59
Condition overlap           : 0
```

The zero overlap confirms that identical machining conditions were not shared between the training and test groups.

---

# 🔬 5-Fold Group Cross-Validation

For the final model comparison, **5-fold GroupKFold cross-validation** was performed.

Identical machining parameter combinations remain within the same fold, providing a stricter estimate of model generalization to unseen machining-condition groups.

## Cross-Validation Results

| Model | Mean R² | R² SD | Mean MAE | Mean RMSE |
|---|---:|---:|---:|---:|
| **Extra Trees** | **0.9738** | **0.0341** | **0.0758** | **0.1479** |
| Gradient Boosting | 0.9675 | 0.0303 | 0.0960 | 0.1792 |
| Random Forest | 0.9655 | 0.0400 | 0.0878 | 0.1744 |
| Linear Regression | 0.9262 | 0.0547 | 0.1987 | 0.2770 |

---

# 🏆 Best Performing Model

## Extra Trees Regression

Extra Trees achieved the highest mean R² under the 5-fold group-aware evaluation.

```text
Mean R²   : 0.9738
R² SD     : 0.0341
Mean MAE  : 0.0758
Mean RMSE : 0.1479
```

The R² scores across the five folds were:

```text
Fold 1 : 0.9856
Fold 2 : 0.9059
Fold 3 : 0.9912
Fold 4 : 0.9918
Fold 5 : 0.9943
```

Therefore, the reported cross-validation performance is:

**R² = 0.9738 ± 0.0341**

The results indicate strong predictive performance across the evaluated unseen machining-condition groups within the available dataset.

> These results measure predictive performance on the available dataset and should not be interpreted as experimental validation of real-world machining performance.

# 🔍 Model-Based Parameter Search

The project includes a parameter-search module that evaluates machining parameter combinations using the trained prediction model.

The objective is to identify combinations associated with lower **predicted surface roughness** within the parameter space represented by the dataset.

## Search Variables

The parameter search considers:

- Depth of Cut
- Feed Rate
- Cutting Speed
- Material
- Cutting Tool

## Search Output

The system reports:

- Recommended Depth of Cut
- Recommended Feed Rate
- Recommended Cutting Speed
- Material
- Cutting Tool
- Predicted Surface Roughness

> The recommended condition represents a **model-predicted result**, not an experimentally verified global machining optimum.

# ⚠️ Project Scope and Limitations

This project is intended as a **machine learning and manufacturing engineering research prototype**.

Important limitations include:

- Predictions depend on the quality and range of the available dataset.
- The dataset contains repeated machining parameter combinations.
- Group-aware validation is used to reduce leakage from identical machining settings.
- Performance outside the represented machining parameter ranges is not established.
- Parameter recommendations are generated from machine learning predictions.
- Recommended parameters have not been experimentally validated on a physical CNC machine.
- The current optimization objective primarily focuses on predicted surface roughness.
- Tool wear, vibration, cutting forces, temperature, energy consumption, and machine dynamics are not fully incorporated into the current predictive model.
- External validation on an independent machining dataset has not yet been performed.

Therefore, the application should be treated as a **decision-support and research prototype**, not as a production CNC control system.
